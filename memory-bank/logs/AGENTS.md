# Logs

Daily session logs for the vibe-* module suite. This is the project history
and the session-to-session handover.

## What Belongs Here

- A dated entry for every session where substantive work happened
- Summaries of changes, decisions, and the reasoning behind them
- Links to changed files, commits, knowledge entries, and projects touched

## Format

- **One file per calendar day**, named `YYYY-MM-DD.md`. Append new `##`
  sections within the same file if you work more than once in a day.
- Frontmatter with `created` / `modified` / `tags` / `summary`.
- One `##` section per topic; bullets with markdown links to affected files.

## Conventions

- Verify the real system date before naming a log file — never assume.
- Logs are mandatory for substantive interactions. If meaningful work was
  done, it must be reflected here.
- Keep entries skimmable: what changed, why, and what's next.
