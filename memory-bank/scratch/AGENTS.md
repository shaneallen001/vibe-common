# Scratch

Ephemeral, throwaway work for the vibe-* modules. Create a dated folder
(`YYYY-MM-DD/`) and stash temporary files, experiments, and one-off notes
there.

## Rules

- **Gitignored.** Everything under `scratch/` except this `AGENTS.md` stays
  local and out of the public repos. Don't put anything here you need to
  survive a clean checkout.
- **Promote when reused.** If files in a scratch folder start getting reused
  across multiple days, move them into a `projects/` folder and record the
  promotion in that day's log with a link.
- **Ephemeral by default.** Old scratch folders can be deleted without
  ceremony.
